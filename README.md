# Happy

Plataforma que liga pessoas a orfanatos para visitação, feita na **Next Level Week #3** da Rocketseat.

## Funcionalidades

- Landing page
- Mapa de orfanatos com Leaflet

## Stack

- React + TypeScript (Create React App)
- React Router, React Leaflet e React Icons
- Docker (Dockerfiles de desenvolvimento e produção)

## Como rodar

```bash
docker compose up
# ou
cd web && yarn install && yarn start
```
